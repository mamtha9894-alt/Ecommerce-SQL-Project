# Ecommerce SQL Project

Simple Ecommerce Database Project using SQL Server.

## Tables
- Customers - Customer Details
- Products - Product Details with Price
- Orders - Order Details

## Features
- Created 3 Tables with Primary Key
- Inserted Sample Data
- Used INNER JOIN to get Customer + Product Details
- Calculated Total Amount using Price * Quantity

## How to Run
1. Open SQL Server Management Studio / Azure Data Studio
2. Open EcommerceProject.sql file
3. Execute the file
